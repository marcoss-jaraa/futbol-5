# Torneo Fútbol 5

1. En Supabase: SQL Editor > pega `supabase.sql` > Run.
2. Authentication > Providers > Email: apaga "Confirm email" (para que entren sin confirmar).
3. Project Settings > API: copia la URL y la clave `anon public`; pégalas arriba de `index.html` (SB_URL y SB_KEY).
4. Sube estos archivos a un repo de GitHub y conéctalo a Vercel (sin build, es estático).
